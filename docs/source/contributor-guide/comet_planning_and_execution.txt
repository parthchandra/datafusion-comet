EXECUTION FLOW
           CometNativeExec.doExecuteColumnar is called on the first Comet operator that is an instance of CometNativeExec.
           CometNativeExec is at the top of a pipeline that is a chain of CometNativeExecs culminating in an operator that is a CometInput, typically a CometScanExec or a CometShuffleExec
           CometNativeExec.doExecuteColumnar collects a list of all the child plans that are Comet inputs,
           It creates an CometExecIterator that will  return the results of the execution of  the native plan.
                CometExecIterator creates a CometBatchIterator for each of the input child plans
                It also creates a native plan from the protobuf representations of the chain of CometNativeExec operators
                The native plan is provided with the list of iterators to the input plans. The leaf operator in the native plan will call the iterators to get the input data.

           The iterators to the input plans are created by calling doExecuteColumnar on the input operators
           CometExecIterator.getNext calls the native plan to get the next batch of results
           The native plan calls the iterators to get the next batch of results from the input plans
           The iterators return the next batch of results from the input plans
